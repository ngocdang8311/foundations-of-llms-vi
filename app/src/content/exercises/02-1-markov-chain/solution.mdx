# (1) Tạo chuỗi huấn luyện bằng cách tách từ ở mỗi dòng theo dấu cách
train_sequence = []
for line in wikitext["train"]["text"]:
    train_sequence.extend(line.split())

print(f"text: {len(train_sequence)} words")
print(f"vocabulary: {len(set(train_sequence))} words")


# (2) Dùng từ điển lồng nhau để đếm các cặp từ (bigram)
bigram_counts = {}
for a, b in zip(train_sequence, train_sequence[1:]):
    if a not in bigram_counts:
        bigram_counts[a] = {}
    if b not in bigram_counts[a]:
        bigram_counts[a][b] = 0
    bigram_counts[a][b] += 1

print(f"distinct pairs: {sum(len(f) for f in bigram_counts.values())}")


# (3) Sinh chuỗi từ bằng random.choices với trọng số là số lần xuất hiện
first_word = "The"
length = 50

import random
random.seed(0)

sample_words = [first_word]
while len(sample_words) < length:
    followers = bigram_counts[sample_words[-1]]
    options, weights = list(followers), list(followers.values())
    next_word = random.choices(options, weights)[0]
    sample_words.append(next_word)

print("\n" + " ".join(sample_words))
